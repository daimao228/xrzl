## 5. 已验证可用的同步模式（botc/room.html）——照这个抄

`room.html` 在真机上验证过「座位同步」正常。核心思想：**没有权威节点，每个客户端定时广播自己的状态，对端按规则合并**。

```js
/* 每 3~4 秒重复广播，丢包/后加入都能自愈 */
function beacon() {
  ch.send('rt_here', { id: meId, name: meName, seat: mySeat, ts: Date.now() });
}
setInterval(beacon, 4000);

/* 座位归属由所有端各自计算，规则一致 → 结果一致 */
const owner = new Array(SEAT_COUNT).fill(null);
peers.forEach(([id, p]) => {
  if (!owner[p.seat] || id < owner[p.seat].id) owner[p.seat] = { id, name: p.name };
});
```

要点：

1. **周期性重播**，而不是"有变化才发"（这是旧实现失败的根因）
2. **无中心**，冲突用确定性规则（id 字典序）收敛
3. 收到消息后立刻重绘
4. 心跳超过 15 秒视为离线

## 6. 旧实现为什么失败（已删除，不要重蹈覆辙）

原来的 `dgzl-online.html` 用的是「房主选举 + 只在变化时广播」：

- 后加入的客户端错过房主那次广播 → 永远拿不到状态
- 两台设备可能同时自认为房主 → 每 2 秒互相覆盖牌局 → **看起来像"自动清空"**
- 座位分配逻辑依赖房主内存里的 `netId`，状态序列化时丢字段 → 认领无效

**整套 `netRole / hostTimer / dg_hello / dg_state / dg_claim` 已经删干净，新代码里 grep 不到。**

## 7. 当前实现要点

### 7.1 房间与身份

- 房间号：`shared.js` 的 `getRoomCode()`，只认 `#room=xxx`
- 名字：优先 `localStorage['botc_lobby'].name`，写进 `sessionStorage` 后钉在这个标签页，允许本页改名
- 每个标签页一个 id（`sessionStorage`，刷新保留）；另有一个每次加载都变的 `sid`，用来判断"刷新了，手牌要重发"
- 刷新不会被当成新设备踢出座位

### 7.2 座位

- 人数 **4～8 可调**，只有结算者（最靠前的在位座位）能改
- 圆桌自动排座：`角度 = -90° + i * 360°/n`，用 `left/top` 百分比定位
- 空位可点，认领后名字同步给所有端；没座位时自动挑最低空位
- 座位冲突：同座位 id 字典序小者赢（id 里带时间戳，越早连上的越优先）

### 7.3 牌局

- 规则：**皇家版** —— 翻开皇冠触发惩罚堆抽牌，抽到皇冠继续抽（原单机版已删，规则以本文件为准）
- **每人只能看到自己的手牌**，别人只显示张数
- 点别人座位上的**发牌区**可以放大看那个人面前的每张牌（罚牌标「罚」、皇冠标 👑），和手牌一样的大卡
- 出牌带卡牌 `uid`，结算者按自己手里的牌核对；对不上就补发手牌
- 回合限制：只有当前玩家能拖牌；被传牌的人才能「相信 / 质疑 / 传给别人」

### 7.4 拍桌

- **没有常驻的「测试拍桌」按钮**，只由牌局触发
- 皇冠触发惩罚堆抽牌时，各端右下角自动出现 **「👋 拍桌」**（约 9 秒后收起）
- 点击后：手掌下落动画 + 桌面震动 + 音效 + 全房间同步（`dg_slam`）
- 音效是 **Web Audio 现场合成**（噪声「啪」+ 低频「咚」+ 木头三角波，每次随机微调），不加载任何音频文件，也不联网
- 浏览器要求先有用户手势才能出声：第一次点屏幕时自动解锁；顶栏有 🔊/🔇 开关，设置记在 `localStorage.dgzl_sound`

## 8. 消息协议（实现版）

所有消息走 `shared/shared.js` 的 `openChannel(handler)`：

| 消息 | 方向 | 载荷 | 用途 |
|---|---|---|---|
| `dg_presence` | 人人广播，每 3s | `{id, name, seat, ts, sid}` | 在线 + 座位认领 + 刷新检测 |
| `dg_game` | 结算者广播，每 2s | `{rev, ts, hostSeat, hostId, count, turn, players:[{seat,name,count,faceUp,lost}], cardInPlay, penaltyCount, over, winner, log, needHands}` | 公共牌局 |
| `dg_hand` | 结算者单发本人 | `{toId, seat, hand, rev}` | 私有手牌（收件人校验 `toId`） |
| `dg_act` | 客户端 → 结算者 | `{id, seat, kind:'play'|'pass'|'accept'|'hand', card:{uid,typeIndex,variant,isCrown}, targetSeat, claim, believe}` | 操作请求 / 手牌上报 |
| `dg_slam` | 人人可发 | `{by, ts}` | 拍桌动画 |

约定：

- **结算者 = 最靠前的在位座位**（座位 1，空出则 2 号顺延），是唯一结算者；每 2 秒重播 `dg_game`
- 客户端只认「当前结算者」或版本号更高的状态；自称结算者但座位不是它的包直接丢掉（防两台互踩）
- 结算者离开（15 秒无心跳）→ 顺延接任，版本号 +1 压过旧状态
- 换结算者后，各人收到 `needHands` 会把自己的手牌上报回来，牌局继续
- 每个客户端都保存"最后一次收到的牌局"，重连/刷新靠重播自动追平
